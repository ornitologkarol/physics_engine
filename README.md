# **2D PHYSICS ENGINE**  
*This project is still ongoing.*    

So far, I learned:
- C++
- Object-Oriented Programming (OOP)
- Separating Axis Theorem (SAT)
- Clipping algorithm
- Space partitioning
- Collision resolution using MTV and velocity changes
